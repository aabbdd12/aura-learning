# AURA Learning — data

The data files used by the sessions of **AURA Learning**, the course of
[AURA](https://aabbdd12.github.io/aura/) (Applied Unified Research Analytics).

In AURA, for instance:

```
use "https://aabbdd12.github.io/aura-learning/data/village.csv", clear
```

| File | Rows | What it is |
|---|--:|---|
| `village.csv` | 8 | Fictitious: the households of a small village, with some unknown values |
| `village2.csv` | 4 | Fictitious: a second village |
| `members.csv` | 13 | Fictitious: the persons of these households |
| `prices.csv` | 2 | Fictitious: one price for each area |
| `messy.csv` | 10 | Fictitious: a file kept by hand, with its mistakes |
| `bkf98I.dta` | 8,478 | Burkina Faso 1998, example data distributed with AURA |
| `mexico_2014_cereals.dta` | 15,866 | Mexico, ENIGH 2014 (INEGI public microdata), example data distributed with AURA |
